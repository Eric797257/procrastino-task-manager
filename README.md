# Procrastino 😂

**The Ultimate "I'll Do It Tomorrow" Task Manager**

Procrastino is a responsive React web app that helps students manage assignments and daily tasks, with funny messages, overdue warnings, and progress tracking to make it less boring.

## Features

- Add tasks with a title, category, and deadline
- Mark tasks as completed or pending
- Edit and delete tasks
- Filter tasks by All, Pending, and Completed
- Funny messages based on task status
- Task statistics: Total, Completed, Pending
- Tasks saved with localStorage (they stay after refresh)
- Responsive design for mobile and desktop

## Technologies

- React + Vite
- Tailwind CSS
- JavaScript
- lucide-react (icons)
- Browser localStorage
- Git & GitHub

## Setup

```bash
git clone https://github.com/Eric797257/procrastino-task-manager.git
cd client
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.
